## 📖 About the Internship

This repository documents my learning journey during the **IBM PBEL 3.0 – Generative AI Internship**.

Throughout the internship, I explored the fundamentals of **Deep Learning**, **Natural Language Processing (NLP)**, **Generative AI**, **Large Language Models (LLMs)**, **Prompt Engineering**, **Diffusion Models**, and **AI Deployment**.

Each day's work is organized into a separate folder containing:

- 📘 README.md
- 📝 notes.md
- 💻 Jupyter Notebook / Python Code
- 📦 requirements.txt
- 📸 Images (where applicable)

This repository serves as both my internship record and a personal knowledge base for future reference.
