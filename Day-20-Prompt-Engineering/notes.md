# Day 20 Notes

# What is Prompt Engineering?

Prompt Engineering is the process of writing clear, structured, and effective instructions that guide Large Language Models to produce high-quality outputs.

---

# Why Prompt Engineering?

Benefits

- Better responses
- Higher accuracy
- Reduced hallucinations
- Better reasoning
- Controlled output format

---

# Components of a Good Prompt

A good prompt should include:

- Role
- Task
- Context
- Constraints
- Expected Output

---

# Good Prompt vs Bad Prompt

Bad Prompt

Tell me about AI.

Problems

- Too broad
- Unclear objective

Good Prompt

Act as an AI Professor.

Explain CNN, RNN, and Transformer.

One example each.

Maximum 200 words.

Result

- Focused
- Structured
- Better quality

---

# Zero-Shot Prompting

Only instruction is provided.

Example

Summarize the following paragraph.

---

# Few-Shot Prompting

Provides a few examples before asking the model.

Advantages

- Better consistency
- Improved accuracy

---

# Role Prompting

Assigns a role to the AI.

Examples

- Software Engineer
- Data Scientist
- Teacher
- Career Mentor

---

# Chain-of-Thought Prompting

Encourages reasoning step by step.

Useful for:

- Mathematics
- Coding
- Logical reasoning
- Complex decision making

---

# Output Formatting

Specify the required format.

Examples

- JSON
- Markdown
- Table
- Bullet Points

---

# Foundation Models

Large pre-trained models adapted for multiple downstream tasks.

Examples

- GPT
- Gemini
- LLaMA
- IBM Granite
- Falcon
